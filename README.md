# proyecto-asir Biblioteca Municipal
Documentación del proyecto de PIMA (1.º ASIR)

Una biblioteca normal de toda la vida que presta libros, presta sus instalaciones para que la gente vaya a estudiar,
pueden ir a leer también, no es obligatorio llevarse el libro. Es una biblioteca de tamaño medio, cuenta con 3 trabajadores.

Problemas:
1. Los libros que prestan y que se devuelven, se anotan en una hoja y luego al final del día se anotan en un excel en un ordendador.
2. Las copias de seguridad de los ordenadores con sus datos se hacen al final de la semana.
3. Los ordenadores para uso público no cuentan con una contraseña.

El repositorio sirve para llevar un seguimiento del proyecto, e ir guardando los archivos que se vayan creando.
